# Запуск Jobly AI с редактором резюме

Нужен Node.js версии 18 или новее и доступ к сервису SourceCraft. Дополнительные пакеты устанавливать не нужно.

1. Откройте PowerShell в папке сайта.
2. Введите токен для текущего окна PowerShell, заменив текст в кавычках своим токеном:

   $env:SOURCECRAFT_TOKEN = 'ваш_токен'

3. Запустите сервер:

   node server.js

4. Откройте http://localhost:3000, выберите «Резюме», создайте или загрузите черновик и нажмите «Улучшить формулировки». Сравните варианты и примените их, если они подходят.
5. Для остановки нажмите Ctrl+C. При открытии нового окна PowerShell переменную нужно задать снова.

Кнопка отправляет профиль, описания достижений и включённые дополнительные разделы во внешний сервис после подтверждения. Отдельные поля контактов, навыков, документов и данные вакансии не отправляются. Если личные данные вручную добавлены в отправляемые текстовые поля, они тоже будут переданы. Проверьте предложения ИИ: он может ошибаться. Сервер предназначен для локального использования одним пользователем; для публикации нужны отдельные меры защиты, ограничения и развёртывание на сервере.

## ИИ-собеседование

После выбора вакансии и заполнения анкеты откройте раздел «Собеседование». Jobly использует описание вакансии, навыки из анкеты и текст ваших ответов, чтобы задавать вопросы и давать обратную связь. Эти данные отправляются сервису SourceCraft. Не сообщайте лишние личные данные. Откройте сайт через http://localhost:3000; при открытии HTML-файла напрямую сервер ИИ недоступен. После изменения server.js остановите запущенный сервер с помощью Ctrl+C и запустите node server.js снова.

## Персональный маршрут

После выбора вакансии и заполнения анкеты откройте «Мой маршрут» и нажмите «Создать маршрут с ИИ». После подтверждения сервер отправит данные вакансии и необходимые ответы анкеты в SourceCraft. Сначала создаётся структура, а подробные материалы загружаются при открытии каждого островка. Для каждого такого запроса требуется доступ к ИИ. Сгенерированные разделы и отметки хранятся в браузере; повторное открытие не создаёт запрос. При изменении анкеты можно создать новую версию, прежние версии и прогресс остаются доступны. Очистка данных браузера удаляет эти локальные данные.

ИИ может ошибаться: проверяйте учебные материалы, условия задач и ответы. Поисковые ссылки не подтверждают качество и доступность ресурсов. Открытые задания сохраняются для самостоятельной проверки; код не исполняется. Изменение срока и нагрузки выполняется в существующей анкете, затем маршрут можно перестроить. При ошибке генерации сохранённый маршрут остаётся доступным. Открытие HTML напрямую через file:// не даёт доступа к серверным функциям; используйте http://localhost:3000. После изменения server.js или route-ai.js перезапустите сервер.

При создании островка теория, практика и проверка запрашиваются последовательно; готовые части сохраняются отдельно. Если запрос прервался, кнопка повтора запрашивает только недостающие части. Диагностика в окне сервера показывает тип этапа, длительность, статус и названия полей, не прошедших проверку. Токен, текст анкеты и ответы модели не записываются в эти сообщения. Каждый этап ожидается до двух минут.

## Диалог с помощником Jobly

Откройте маскота и задайте вопрос. Enter отправляет сообщение, Shift+Enter добавляет строку. Переписка существует только до обновления или закрытия страницы; кнопку «Очистить диалог» можно использовать раньше. Вопрос, последние сообщения и название текущего раздела отправляются в SourceCraft. Не вводите лишние персональные данные. Если включить флажок согласия, дополнительно передаются название выбранной должности и отмеченные уровни навыков из анкеты. Контактные данные и остальные ответы анкеты автоматически не передаются. Быстрые действия работают и без токена. Для диалога задайте SOURCECRAFT_TOKEN в том же окне PowerShell и перезапустите node server.js, затем откройте http://localhost:3000. Если открыть HTML напрямую, запросы к серверу работать не будут.
